# v0.1.1 界面逻辑复盘与修改计划

本文记录 v0.1.1 的产品逻辑、已执行优化和验收证据。目标是让普通用户按自然顺序完成：

    打开/保存白板 → 准备讲稿 → 录制原始素材 → 录后编辑 → 导出成片

## 一、核心使用逻辑

### 1. 项目先行

用户只需要设置一个项目文件夹。白板、附件、原始录制、会话事件、逐字稿、字幕、编辑决策和成片都在这个目录下。界面必须避免出现多个“保存位置”。

对应动作：

| 命令 | 语义 | 是否改变当前白板 | 是否读取项目内容 |
| --- | --- | --- | --- |
| 设置项目文件夹 | 建立项目根，设置后只显示路径提示 | 否 | 否 |
| 打开 Excalidraw 文件 | 只打开一个白板文件 | 是 | 否 |
| 保存白板 | 把当前白板和项目清单写入项目根 | 否 | 否 |
| 在 Finder 中显示 | 打开当前项目目录 | 否 | 否 |

### 2. 录制前只准备讲稿，不出现“文字轨”

录制前只有讲稿。逐字稿、字幕和智能粗剪都必须来自录制后的真实音频或导入的录后资产。

因此录制面板使用：

    项目 → 提词器/讲稿 → 摄像头画中画 → 录制

### 3. 停止后先保存原始录制，再进入录后编辑

“原始录制”和“成片”必须区分：

| 名称 | 产生时机 | 路径 | 是否最终交付 |
| --- | --- | --- | --- |
| 原始录制 | 停止录制后 | recordings/<session-id>/ | 素材 |
| 成片 | 录后编辑并导出后 | exports/final.mp4 | 最终输出 |

录后编辑器只写时间线，不破坏原片。

## 二、已执行修改

### 项目与路径

- 收敛为单一项目根目录；
- 新增 schema v2：`project.excalicord.json` 只保存相对路径；
- “设置项目文件夹”会创建新的项目上下文，不继承上一项目录制和编辑数据；
- 后续面板清理中移除“打开项目文件夹”加载入口，避免与 Finder 打开行为混淆；
- “打开 Excalidraw 文件”只替换当前白板，不改变项目根；
- 录制开始前必须已有项目文件夹。

### 录制会话

- 每次录制写入 `recordings/<session-id>/`；
- 保存 `session.json` 和 `events.json`；
- 事件统一为录制开始后的毫秒时间基；
- 旧混合录制会如实标记 `legacyComposite`，不伪造独立摄像头或音频资产。

### 录后编辑

- 增加独立录后编辑工作台；
- 支持非破坏剪辑、恢复、撤销、重做和自动保存；
- 支持本地 faster-whisper 逐字稿；
- 原始逐字稿、校正版和修正记录分开保存；
- 字幕可从校正版生成并导出 SRT/VTT；
- 智能粗剪会识别长静音、前摇、重说、结尾空白；
- 长静音内如果存在 Frame 切换、点击或指针演示，默认要求人工复核；
- Smart Camera、光标点击、字幕、画面和音频配置进入同一渲染链路；
- 成片固定写入 `exports/final.mp4`；
- VideoToolbox 硬件编码器不可用时自动回退到软件 H.264。

### README 与文档

- README 首屏和功能说明更新到 v0.1.1；
- 新增录制面板、录后编辑工作台、成片抽帧接触表；
- 增加项目格式说明；
- 更新快速开始、安装、使用说明、常见问题和开发说明。

## 四、仍需后续版本处理的边界

- 当前 Capture Agent 录制的是混合原片，摄像头若已烧入原片，录后不能重新拆分定位；
- 真正独立的 webcam/microphone/system-audio 资产需要下一阶段采集链路支持；
- QuickTime/Finder 前台目检受系统锁屏影响时，只能用全量解码和抽帧作为替代证据；
- 浏览器 CJK 字体 CDN 403 属 Excalidraw 外部资源问题，当前插件逻辑不依赖这些字体成功加载。

## 五、后续优化建议

1. 增加“新建项目”显式按钮，使“设置项目文件夹”的语义更直观；
2. 支持独立摄像头/麦克风轨采集，解除 `legacyComposite` 限制；
3. 在录后编辑器增加更明显的“原片/成片”时长差异解释；
4. 为智能粗剪增加“保守 / 标准 / 激进”三个策略；
5. 为项目目录增加一键健康检查：缺失文件、路径越界、字幕不同步、录制不存在。
