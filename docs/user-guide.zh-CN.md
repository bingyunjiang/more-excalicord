# 使用说明

## 悬浮栏

悬浮栏包含：

- +：新增幻灯片
- 幻灯片总览：查看、搜索、排序、删除和重命名幻灯片
- 白板控制：总览、缩放、聚焦、撤回、前进、播放和设置
- 录制面板：项目、提词器、摄像头、麦克风和录制

## 幻灯片

幻灯片基于同一张 Excalidraw 白板中的 Frame 实现。用户界面统一称为“幻灯片”。

新增幻灯片默认按每行最多 6 张横向排版，超出后自动换行。新增后默认展示整块白板布局。

## 白板控制

白板控制包含视图和设置：

- 白板总览
- 聚焦指定幻灯片
- 放大 / 缩小 / 恢复 100%
- 撤回 / 前进
- 播放
- 悬浮栏位置
- 新增后全局鸟瞰
- 幻灯片智能吸附
- 显示白板网格

## 录制

### 先设定项目文件夹

一个项目只使用一个项目文件夹。录制面板提供四个含义不同的显性命令：

- 设置项目文件夹：建立新的项目文件夹，设置后路径以小字号显示在按钮下方；录制、字幕、成片和项目清单都写入这里；
- 打开 Excalidraw 文件：只打开一个 `.excalidraw` 文件，不改变当前项目文件夹；
- 保存白板：与打开白板放在同一行，把当前场景、附件和项目清单写入项目文件夹；
- 在 Finder 中显示：只打开当前项目目录。

设定项目后，先点击“保存白板”建立项目清单；此后不需要再为录制、字幕或成片选择其他保存目录。若要继续已有白板，使用“打开 Excalidraw 文件”载入白板内容。

开始录制后，主面板会自动收起，只保留带时长变化的悬浮开始 / 暂停 / 停止控制条。麦克风可在录制设置里选择默认或指定设备；光标可调整高亮形式、鼠标形状和点击提示音。

摄像头画中画里有两类补光：虚拟补光会直接增亮摄像头画面；屏幕补光会在电脑屏幕边缘显示柔光，用屏幕给人脸补光。macOS 录制时若 Apple 原生边缘光处于启用状态，插件会自动隐藏自研补光，避免重复叠加。屏幕补光默认关闭，需要用户自行勾选。

录制范围包括：

- 选择的屏幕/窗口
- 白板全景
- 当前幻灯片聚焦

摄像头画中画可以作为屏幕气泡显示，也可以合成进导出视频。录制相关功能以实际导出视频播放为最终验收。

停止录制后产生的是“原始录制”，会保存到 `recordings/<session-id>/`。同目录的 `session.json` 和 `events.json` 记录 Frame、指针和点击事件。原片可播放或保存，但还不是最终成片。

## 提词器、逐字稿和字幕

- 提词稿：录制前计划说什么，不绑定实际音频；
- 逐字稿：根据录制音频识别实际说了什么，保留词级时间戳；
- 字幕：从校正版逐字稿生成并用于成片显示或 SRT/VTT 导出。

三者不会互相覆盖。提词器可载入 md、txt、srt 或 vtt 文件；其中 srt/vtt 只提取文字作为讲稿。修改逐字稿时，原始 ASR 保存在 `transcript.raw.json`，校对结果和修改记录分别保存。

## 录后编辑

录制完成后点击“进入录后编辑”。工作台包含：

- 剪辑：设置入点/出点，添加或恢复非破坏剪切；
- 逐字稿：运行本地识别、导入词级 JSON、结合原音校对；
- 智能粗剪：分析前摇、收尾、停顿、重说和填充词，只生成建议；
- 字幕：从校正版生成，逐条修改，导出 SRT/VTT；
- 镜头：根据 Frame、鼠标和点击重算聚焦轨迹；
- 光标：显示、大小、平滑和点击强调；
- 摄像头：独立素材可改位置和大小，合成原片会显示不可拆分提示；
- 画面/音频：背景、圆角、留白、阴影、音量和淡入淡出。

长静音期间如果存在 Frame 切换、点击或指针演示，智能粗剪会要求人工复核。点击“导出成片”后，最终文件固定写入 `exports/final.mp4`；“打开成片”与“在 Finder 中显示项目”是两个不同动作。

## 项目目录

    项目文件夹/
    ├── project.excalicord.json
    ├── scene.excalidraw
    ├── recordings/<session-id>/
    │   ├── 原始录制.mp4
    │   ├── session.json
    │   └── events.json
    ├── text/
    │   ├── script.md
    │   ├── transcript.raw.json
    │   ├── transcript.corrected.json
    │   ├── transcript.corrections.json
    │   ├── subtitles.srt
    │   └── subtitles.vtt
    └── exports/final.mp4

完整目录结构、schema 和安全原则见[项目格式](project-format.zh-CN.md)。

## 本地数据与权限

- 当前主要面向本机自托管部署；白板、原片、逐字稿和成片默认保存在用户选择的项目目录；
- 摄像头、麦克风和屏幕录制只在用户主动启用并授权后读取；
- 白板、Frame 与浏览器共享录制可保留独立摄像头素材；Native 桌面合成录制会把人像写入主视频，更适合直接交付；
- Capture Agent 严格限制可写项目路径，拒绝绝对路径、反斜杠、`..` 和任意目录写入；
- Native overlay 在支持的桌面录制链路中设置为不进入屏幕共享；浏览器兜底录制仍应通过实际回放确认。
