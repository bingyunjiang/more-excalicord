# 品牌资源

本目录存放 more-excalicord 的公开品牌图形资源，可用于 README、GitHub 仓库页、Release 说明、演示文档和部署教程。

| 文件 | 用途 |
| --- | --- |
| `more-excalicord-logo.svg` | README 顶部、文档页横向 logo |
| `more-excalicord-icon.svg` | 方形图标、插件卡片、安装说明 |
| `favicon.svg` | 网页 favicon 或小尺寸图标 |
| `social-preview.svg` | GitHub social preview、分享封面或项目介绍图 |

这些资源均为 SVG，适合直接入库、复制和二次导出。若需要 PNG，可用浏览器、设计工具或命令行工具从 SVG 导出。
